
# TourEase – AI-Powered Tour Guide App

During our final year project, our team of four noticed that most travel guides—apps or human—gave the same generic suggestions to everyone. Travelers often miss interesting places, and planning trips can be confusing with too much information online.

To address this, we built **TourEase** ∴ a simple AI-powered tour guide that adapts to user preferences, suggests places in real time, and integrates with Google Maps. We developed it using Flutter → Firebase → Gemini API.

After building the prototype and exploring the idea, we decided not to continue further, but the project taught us how to combine AI, maps, and real-time guidance in a practical app.

---

## Features

• Personalized travel suggestions using AI
• Customizable itineraries and trip management
• Real-time navigation with Google Maps
• Secure sign-in and cross-device data sync via Firebase

## Tech Stack

⇒ **Frontend:** Flutter
⇒ **Backend:** Firebase (Authentication, Cloud Storage, Analytics)
⇒ **AI Integration:** Gemini API
⇒ **Maps Integration:** Google Maps API (Places)
⇒ **State Management:** Provider
